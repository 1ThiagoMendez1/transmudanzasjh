# **App Name**: TrajectoFlow

## Core Features:

- Journey Dashboard with Visual 'Snake' Tracking: Visualize active logistics journeys on an intuitive dashboard using a dynamic 'snake' graphic, highlighting key event nodes in real-time. This includes the 'Header dinámico' with live financial indicators and the interactive 'snake' in the central zone.
- Public Tracking Page by Guide Number: Provide a public web page where clients can input a unique 'GUIA' number to view their shipment's current status, a simplified visual 'snake' of the journey, event history, photos, and delivery details. Automatic link generation and WhatsApp integration for tracking links.
- Interactive 'Snake' Event Details: Enable users to interact with individual event nodes on the visual 'snake' (e.g., hover, click) to reveal comprehensive details such as client information, addresses, associated photos, and real-time costs for that specific event.
- Real-time Journey Financial Management: Allow recording of initial assigned funds and real-time expenses (fuel, tolls, food, maintenance, extras) for each journey. Display current financial status, generate alerts for budget overruns, and support driver expense submissions with photos.
- Quote-to-Journey Conversion: Provide a streamlined web form for creating new quotes with client, dates (loading, delivery, return), tonnage, and truck type, with the core functionality to automatically convert an accepted quote into an active journey.
- Financial Journey Closure & Reporting: Upon a journey's visual 'closure' (snake completion), automatically generate a summary of total income, expenses, net gain, and profitability by route, sub-routes, and added clients.
- AI Expense Prediction Tool: Utilize an AI tool to provide anticipated expense suggestions for new journey types or routes based on historical financial data and similar completed trips.

## Style Guidelines:

- Primary accent color: A vibrant, elegant green (#58C322) chosen to reflect growth and modernity, conveying an 'alegre' yet professional feel without being corporate.
- Background color: A very subtle, heavily desaturated light green (#F1F5F0) to ensure a clean, airy 'UX premium' environment that highlights interactive elements and vibrant data.
- Secondary accent color: A bright, analogous yellow-green (#AEF740) to provide contrast and energy for microinteractions, call-to-action elements, and highlight key visual aspects.
- Body and headline font: 'Inter' (sans-serif) for its modern, clean, and highly readable characteristics, suitable for extensive data display and embodying a 'startup moderna' aesthetic.
- Utilize minimalist, clean-line icons with soft fills, designed to complement fluid animations and the overall modern, intuitive UI, focusing on clarity over complexity.
- Implement a dynamic and innovative dashboard layout, featuring a prominently animated central 'snake' for active journey visualization, a non-fixed side panel for details on demand, and a timeline-style footer for event logging, all with ample, well-distributed negative space.
- Integrate fluid animations and microinteractions throughout the platform, including smooth transitions for the growing/closing 'snake' visualization, subtle hovers for event node summaries, and animated panel expansions to create a highly dynamic and engaging user experience.
